# 마블 레이스 (Shorts용)

단일 파일 게임입니다. `index.html`을 브라우저로 열면 바로 실행됩니다. 빌드나 라이브러리가 필요 없습니다.

- 화면비 9:16(1080x1920). 한 라운드는 약 1분입니다. (카운트다운 3초 + 레이스 최대 49초 + 결과 8초)
- 라운드가 끝나면 맵(5종 순환), 시드, 시작 위치가 바뀌어 자동으로 다음 판이 시작됩니다.
- 화면 구성(타이머, TOP 5, 진행 트랙, 하단 문구)은 매 라운드 동일합니다.

## 옵션
- 우측 상단 ⚙ 버튼: 참가자 이름(한 줄에 하나)과 공 개수를 설정합니다. 브라우저에 저장됩니다.
- URL 파라미터: `?names=민수,지영&balls=12&seed=1&map=0~4&clean=1`
  - `clean=1`: 설정 버튼을 숨깁니다. (녹화용)
  - `seed`, `map`: 같은 결과를 재현하거나 특정 맵을 고정합니다.
- Space: 다음 라운드로 넘깁니다.

## 녹화
`?clean=1`로 연 뒤 브라우저 창을 세로(9:16)로 맞추고 OBS 등으로 화면을 녹화합니다.
